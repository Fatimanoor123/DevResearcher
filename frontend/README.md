# DevResearcher Clean Frontend

Clean React/Vite IDE-style frontend for the DevResearcher FastAPI backend.

Features:
- Native Windows Open Folder integration
- Explorer/project tree
- Monaco editor and tabs
- Save with Ctrl+S
- Run current file
- Markdown preview
- Search and replace
- Git status/stage/unstage/commit
- Integrated terminal over `/ws/terminal`
- DevResearcher agent over `/ws/agent`
- Streaming output and backend health

See `INSTALLATION.txt`.
